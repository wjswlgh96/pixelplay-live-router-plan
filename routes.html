현행 라우터

production(pixel-play.studio)에 배포된 실제 라우터입니다.

라우터역할접근비고
/라이브 목록(인덱스).공개필터(전체·팔로잉·방금 시작·채팅 활발)·정렬, Hero, 사이드바(팔로잉·트렌딩·인기 키워드). get_live_list() 단일 snapshot.
/live구 목록 경로.리다이렉트next.config redirects로 /로 이동합니다.
/live/search라이브 검색.공개?query=. 태그 정확 일치(GIN)와 제목·닉네임 검색 분리, 전체 결과 수 노출.
/live/[creatorId]라이브 시청.공개 읽기채팅 입력·팔로우·후원·투표 참여는 로그인 필요. 후원 랭킹(익명은 동물 닉네임), 후원자 채팅 배지.
/live/[creatorId]/chat채팅 팝아웃.공개 읽기방송 운영 화면의 채팅 분리 보조창.
/live/[creatorId]/chat/[overlayKey]OBS 채팅 오버레이.토큰 URLHMAC overlay key 검증 후 service role snapshot RPC 조회, Realtime 반영.
/live/[creatorId]/alerts/donation/[overlayKey]OBS 후원 알림 오버레이.토큰 URL후원 수신 시 알림 템플릿·사운드·Web Speech TTS 표시.
/channel/live방송 운영.본인만방송 시작·종료, 태그, 투표 생성·종료, MediaMTX 송출 상태 표시.
/channel/chat채팅 설정.본인만참여 범위, 팔로워 대기 시간, 슬로우 모드, 링크 차단, 금칙어, 채팅 규칙.
/channel/security방송 연결.본인만스트림 키·OBS 오버레이 URL 발급·재발급. 카드별 물음표 버튼으로 OBS 연결 단계별 가이드(캡처 이미지·확대) 제공. 메뉴명은 "방송 연결"로 변경.
/channel/donation후원 설정·대시보드.본인만최소 후원 금액, 알림 표시 시간·알림음·볼륨, TTS 음성·속도, 채팅창 후원 메시지 노출.
/channel/settlement정산.본인만연도·상태·정렬별 정산 상세와 연도별 총 정산액.
/channel/analytics/live, /channel/analytics/report통계 분석.본인만실시간 통계(팔로우 이벤트 Realtime)와 지난 방송 분석(채팅 참여자 등).
/channel/[creatorId]공개 채널 홈.공개라이브 Hero, 배너, 커뮤니티 미리보기. 본인 채널이면 "내 채널 설정" 노출.
/channel/[creatorId]/community채널 커뮤니티(게시판).혼합열람 공개. 글 작성은 크리에이터만, 댓글·좋아요는 로그인 유저. 상세 /[postId], 작성 /write.
/channel/[creatorId]/setting채널 관리.본인만채널 소개(bio), 홈 배너(최대 5개, 순서·삭제).
/user/profile프로필 설정.로그인 필요/user 기본 이동 대상.
/user/following팔로잉 목록.로그인 필요필터·번호형 페이지네이션.
/user/donations후원 내역·포인트 충전.로그인 필요지갑 잔액, Toss 충전, 연/월별 후원·충전 내역(get_user_donation_snapshot_v2).
/user/donations/toss/success, /toss/failToss 결제 콜백.로그인 필요결제창 완료·실패 리다이렉트 처리.
/api/payments/toss/prepare, /confirmToss 충전 준비·승인 API.서버 처리금액 검증 → Toss 승인 → confirm_wallet_charge 멱등 반영. webhook 라우트는 채택하지 않았습니다.
/api/channel/live/stream-status송출 상태 조회 API.서버 처리MediaMTX Control API를 서버에서 대리 조회합니다.
/api/auth/withdraw회원 탈퇴 API.서버 처리service role로 계정·스토리지 정리.
